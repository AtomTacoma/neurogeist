# Neurogeist — site

Single-file band site for neurogeist.com. Open `index.html` in a browser; no build step.

- `index.html` — the whole site (logos and the DISPLAYED font are embedded)
- `img/` — source logo vectors
- `fonts/` — web font source
- `audio/` — drop EP tracks here as `01.mp3` … `05.mp3` and the player switches from the synth placeholder to real files
- `photos/` — images for the Visual section; list them in the `PHOTOS` block at the bottom of `index.html`

Edit tracks, shows, merch and photos in the `DATA` block at the bottom of `index.html`.
